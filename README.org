This repository is a personal configuration. The actual development of ~dpacker~ happens [[https://github.com/aocoronel/dpacker.h][here]].

** How to use

#+BEGIN_SRC bash
  ln -s config/void.c dpacker.c // Void
  ln -s config/artix.c dpacker.c // Artix
  cc @build && ./make
  ./dpacker
#+END_SRC

** How does it work?

~dpacker~ uses ~libalpm~, which is the ~pacman~ database library. It compares all packages defined in ~dpacker.c~ with the packages installed in the system. Then it installs missing packages from system repos and AUR (using a PKGBUILDs in ~./pkg~), and uninstalls packages not in the list.
